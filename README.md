# 다물초이

[![solved.ac 프로필](https://mazassumnida.wtf/api/v2/generate_badge?boj=zkzk1351)](https://solved.ac/zkzk1351)

결제 시스템과 PG·핀테크 기술에 관심이 있습니다.

돈이 오가는 흐름은 한 번의 실패가 곧 사용자 손해가 되기 때문에,
"왜 이렇게 설계했을까"를 끝까지 따져보는 편입니다.
기술 쪽 흐름만 보는 것보다, 가맹점과 정산처럼 사업에 가까운 쪽까지
같이 이해하는 사람이 되고 싶습니다.

## 관심 분야

- **결제 상태 흐름** — 인증에서 승인, 매입으로 이어지는 단계와 부분취소.
  상태가 갈릴 때마다 사용자에게 무엇을 보여줄지 정하는 일에 관심이 있습니다.
- **결제의 예외 처리** — 승인 실패, 입금 대기, 중복으로 도착하는 웹훅처럼
  정상 흐름에서 벗어난 경우를 어떻게 다룰지.
- **가맹점과 정산** — 결제는 승인에서 끝나지 않고 수수료와 정산 주기,
  가맹점이 정산 내역을 확인하는 화면까지 이어집니다.
  가맹점 입장에서 무엇이 필요한지에도 관심이 있습니다.
